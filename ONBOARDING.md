- /plan-maker — Breaks down a feature or fix into a structured task list. Use before starting anything multi-step.
- /feature-refinement — Refines a rough feature idea into a scoped brief with decisions captured. Use before planning.
- /implement-all — Executes every uncompleted task in a plan file, one commit per task, using background agents. The team's primary delivery loop.
- /implement-next — Implements the next single uncompleted task in a plan file. Use when you want finer control than /implement-all.

- /session-history — Shows what happened in recent past sessions. Useful for resuming after a break.
