# Learnings

## What Has Failed
- **[2026-07-29] (×12) pytest OOM / parallelism**: `-n auto` on real-model lanes OOM-crashed the 48GB machine; use `-n 8` (stubs ~0.3GB/worker, never `-n auto`/`-n0`). Clear check: `ps -Ao comm=,args= | awk '$1 ~ /[Pp]ython/ && /bin\/pytest/'`; full suite always backgrounds → subagents run scoped foreground, coordinator runs full suite once at end.
- **[2026-07-05] (×3) implement-all**: no-bundle (temp defaults task 1, thread callers later); fix-agent prompts ≤5 targeted fixes; recovery-check violations emit full What/Why/Fix/Prevention block; `git status --porcelain` at 100%.

## What Has Worked
- **[2026-07-31] (×16) Backlog "bug" briefs**: run existing reproducing test first — may already be fixed. Fix-at-route ≠ fully fixed (verify full request path). Report fixed-with-SHA. Net-new = ONE assertion in strongest existing test. "Still listed"=weak proxy. Dry-run repro: existing tests stub the destructive fn AND point paths at non-existent files → vacuous; repro needs a REAL existing file + un-stubbed fn (install.py Step-0 `_remove_legacy_service` had no dry_run guard).
- **[2026-07-28] (×15) regression-guard files**: `path_home_allowlist.txt` pins (file,lineno,sha) — shifts on any added line above callsite. OpenAPI snapshot: regen with `--update-openapi-snapshot` on 3.12. New SearchConfig field: dataclass+`_apply_toml`+coerce+snapshot tests. `response_model=None` trips `test_no_empty_schemas_remain`.
- **[2026-07-27] (×10) CLI HTTP-proxy conversion**: grep `tests/` for all patches of removed symbols first; mock `httpx.get/post/delete` (patch where USED). `ConnectError` before `HTTPError`. Test env key must be 64-char hex. Non-terminal `.get(field, sentinel)` in a `while` loop = silent hang → explicit None + fail-fast.
- **[2026-07-21] (×10) adding a column to schema/CollectionMeta**: mirror ALL sites: dataclass, `_row_to_meta`, BOTH meta-write fns, all ctor sites, `_ROUTING_FIELDS` (omit job-id). Still needs `_migrate_<field>()` wired + catalog entry, even if no STORE_SCHEMA_VERSION bump.
- **[2026-07-17] (×9) job-spawning REST route**: guard→404→create→`transition({QUEUED},RUNNING)` BEFORE `create_task`→`_background_tasks`+`add_done_callback`. 409 via persisted `meta.<job>_job_id` lazy-stale-clear. Declare `response_model=`+`responses=` or snapshot documents empty `{}`.
- **[2026-07-29] (×6) collection visibility = meta-in-namespace**: gate on `get_collection_meta(name,ns) is not None` (not config only); list unions config+ns_names. Bare `MagicMock` on `get_collection_meta` → stub as `AsyncMock(return_value=None)`. `POST /route` root cause: pass store metas as `initial_metadata` into router.
- **[2026-07-05] (×6) xdist/asyncio/stub**: module-level stubs must restore immediately; absent-pkg simulation via `monkeypatch.setitem` is vacuous if already imported → subprocess or del+reload. `asyncio.run()` not `get_event_loop()`. `async def` → `AsyncMock`. MCP tests need `xdist_group("mcp")`.
- **[2026-07-21] (×6) test vacuity**: `assert a in x or b in x` → separate asserts. Guard loops with `assert results` first. Exception-path tests need `assert_awaited_once()`. Override tests start at OPPOSITE value. `MagicMock(name=...)` sets display name, not `.name`.
- **[2026-07-06] (×5) LanceDB quirks**: `.limit()` is scan limit not sort-then-limit. `merge_insert().when_matched_update_all()` replaces whole row. Missing table → `ValueError("Table not found")`. `count_rows(filter=)`. `db.close()` sync. SQL via `_where_eq`/`_where_in` never f-strings.
