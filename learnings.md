# Learnings

## What Has Failed
- **[2026-07-05] BE-7 stacked full-suite pytest OOM**: stacked/backgrounded `uv run pytest` with `-n auto` (14 workers × ~2GB fastembed/onnxruntime/torch) crashed the machine (Jetsam + WindowServer watchdog). `-n 4` is pinned in `addopts` — never restore `-n auto`, never add `-n0` outside debugging. Run ONE suite at a time: `pgrep -fl pytest` must be empty before any run, never background a full run, wait for workers to exit if a run timed out, iterate on scoped paths (`tests/x.py --no-cov`), run the full suite once in the foreground at task end.
- **[2026-07-05] E2d BE-1 no-bundle rule**: adding a required store param does NOT justify bundling caller tasks into one commit. Use a temporary default (`ns: str = DEFAULT_NAMESPACE`) in task 1, thread call sites in later tasks, remove the default in a cleanup task.
- **[2026-06-28] session-limit / oversized agents**: an agent returning "session limit" with zero tool uses → respawn with identical prompt (work was well-specified, only wall-clock failed). Keep fix-agent prompts ≤5 targeted fixes; for 10+, split sequentially or apply directly in main context.
- **[2026-07-05] /implement-all literal compliance failures**: (1) Progress lines MUST appear in the final user-visible text message of each iteration — mid-turn text between tool calls may not display; copying them just before the Agent launch is not enough. (2) Violations MUST be filed in the exact structured format (`- Task [N.M] failed ❌: What / Why / Fix / Prevention`) — prose summaries do not satisfy the requirement. (3) After the plan reaches 100%, check `git status --porcelain` before declaring done — late background agents can leave uncommitted changes.

## What Has Worked
- **[2026-07-05] xdist stub / sys.modules isolation**: any file installing a stub into `sys.modules` (e.g. `fastmcp`, `spacy`) at module level MUST restore the real class at module level immediately — `--dist=loadgroup` imports every file in every worker at collection, so fixture teardown is too late and leaks poison all workers. To simulate an absent package, set `sys.modules["pkg"] = None` and restore in `finally`.
- **[2026-06-29] asyncio in xdist workers**: always use `asyncio.run(coro)` (or `@pytest.mark.asyncio`); `get_event_loop().run_until_complete()` raises in xdist workers. `asyncio.run()` is safe from the main test thread inside `with TestClient(app):` (app runs in its own loop). But NEVER `asyncio.run()` async methods on the server's own store object — locks bind to a dead loop; open a fresh `SearchStore`/`lancedb.connect_async(db_path)` inside the async fn instead.
- **[2026-07-05] AsyncMock for async methods**: mock any `async def` (GraphStore GC methods, lancedb leaf calls `execute`/`to_arrow`/`to_list`) with `AsyncMock`, not `MagicMock` — `await MagicMock()` returns a coroutine wrapper, a silent wrong-value pass. Mock lancedb *table* objects as `MagicMock` (builder chains are sync); set `db.open_table = AsyncMock(return_value=table)`. `Mock` `side_effect` lambdas must accept new kwargs (`lambda coll, ngrams, ns="default": ...`) or they raise TypeError swallowed by pipeline fallback.
- **[2026-07-05] xdist_group conventions**: any file with even one MCP test needs `xdist_group("mcp")` in `pytestmark`; `benchmark`-marked tests need `xdist_group("benchmark")` (and are NOT excluded from the default suite — only `live_benchmark` is).
- **[2026-06-29] path_home_allowlist ratchet**: `test_no_hardcoded_path_home.py` pins `(file,lineno,sha)`; ANY line added above a `Path.home()` callsite in `config.py` (dataclass field, import) breaks it. After editing config.py run it with `-n0 --no-cov`, then update the line number in `tests/path_home_allowlist.txt` (sha unchanged). Adding a `SearchConfig` field also needs: dataclass+`_apply_toml`+`_coerce_bool`/`_coerce_int` blocks, and the `test_config_defaults.py` snapshot.
- **[2026-06-29] OpenAPI snapshot regen (Python 3.12)**: adding/removing any Pydantic response-model field breaks `tests/server/test_openapi_snapshot.py`; regen with `uv run --python 3.12 pytest tests/server/test_openapi_snapshot.py --update-openapi-snapshot` (CI is 3.12; 3.13 differs on 422 text). Only `tests/server/openapi_snapshot.json` is the guard. A single-test invocation's "coverage not reached" is expected, not a failure. `response_model=None` also fails `test_no_empty_schemas_remain` — always name the JSON response model.
- **[2026-06-29] exact field-set / model_dump() snapshot tests are regression guards**: adding a field to any Pydantic model breaks exact `model_dump()` / field-set assertions across sibling files (e.g. `test_mcp_schemas.py`, `test_routes_search_acl.py`). Grep `tests/` for the class name and update them in the same change — never weaken them. Use `Model.model_fields.keys()` to enumerate full field sets rather than hand-curating (a partial set is a coverage illusion).
- **[2026-07-02] eval baseline regeneration**: any change to `eval/backends.py` or `eval/runner.py` changes `eval_hash`; run `uv run python tests/eval/baselines/regenerate.py` or `test_baseline_contract.py` fails "stale baseline". Adding eval corpus docs shifts `routing_mrr` (centroid change) even if graph queries are excluded — update `thresholds.toml` floors (within `max_floor_drop_without_waiver` 0.05) and regen baseline twice. Retrieval-only collections must NOT go in `routing/collections.jsonl`. New `EvalMetrics` metric → add to `_QUALITY_METRIC_FIELDS`. Gated eval tests passing `baseline_path` MUST call `assert_thresholds(report)`.
- **[2026-07-02] STORE_SCHEMA_VERSION propagation**: bumping it breaks tests asserting the old value AND two hardcoded production defaults — `pipeline.py` (`… else 0`) and `routes_collections.py` stub-meta default. Grep `schema_version=0` and `else 0` before bumping; add a `MigrationSpec`. `apply_in_place_migrations` dispatches zero-arg methods (global, iterate all collections, per-table schema guard), so `POST /collections/foo/migrate` migrates ALL collections.
- **[2026-07-03] adding a `_meta_schema()` / `CollectionMeta` column**: update ALL of `_row_to_meta` (read), `update_collection_meta` (write dict), AND `_do_write_meta_unlocked` (raw dict — silently wiped on every ingest-triggered centroid update if omitted), plus `pipeline.recompute_collection_meta`'s constructors. Adding a `get_collection_meta` call to `ingest_file`/`ingest_directory` breaks inline mock stores (add `async def get_collection_meta(self,*a,**kw): return None`) and `assert_awaited_once_with` (use `assert_any_call`).
- **[2026-07-02] LanceDB quirks**: `.limit()` is a scan limit, not sort-then-limit — for Python-side sorted pagination fetch all up to a ceiling constant (`_EXPIRING_SCAN_CEILING`) THEN sort THEN paginate. `add_columns`: pass a `pa.field(...,nullable=True)` for nullable columns, the dict form `{"col":"cast(0 as bigint)"}` only for non-nullable defaults. `merge_insert().when_matched_update_all()` REPLACES rows (can't increment counters — persist incidence rows, derive counts at read). New columns in the ingest row dict need a `has_x_cols = 'x' in [f.name for f in table.schema]` guard or LanceDB auto-evolves un-migrated tables. Local `connect_async()` `db.close()` is sync — no `await`.
- **[2026-07-02] TOML `[collections]` section format**: `make_real_app(toml_content=...)` needs `[collections]\ncollections=["/path"]\n` (section header) — a bare top-level `collections=[...]` is silently ignored. Integration tests needing `get_collection_meta` to find a collection must register it via `POST /collections` (or full ingest); a TOML path is config-only and writes nothing to the store.
- **[2026-06-28] TypeSpec `namespace` reserved word**: never use `namespace` (or `model`/`interface`/`op`/`enum`) as a param name in `.tsp` — causes `multiple-blockless-namespace` errors; use `ns`. Use `union` (not `enum`) for string-literal sets (cleaner oneOf). Optional-with-null fields need `field?: T | null` (with `?`) or OpenAPI marks them required. `@doc` on a response body sets the schema description — extract a named model for an HTTP response description. TypeSpec compiles clean yet can contradict the plan (nullable vs non-null counts, plain-string vs structured `detail`) — diff generated OpenAPI against plan + sibling `routes_*.py`.
- **[2026-06-29] test-assertion pitfalls**: (1) multi-leg/fanout tests — never `assert a in x or b in x` (passes on one leg); use separate asserts and also assert `{r["collection"] for r in results}` spans every expected collection. (2) always guard `for r in results:` / negative `not any(...)` / `if results:` with `assert results` (non-empty) first — empty makes them vacuously pass. (3) presence before value: `assert "f" in data` then index `data["f"]`. (4) don't set/assert phantom attributes the production code never reads, or check membership of a str in a `list[dict]` (`col not in excluded_dicts` is always True — assert `== []`). (5) override tests must start the mock at the OPPOSITE value; per-collection tests need `side_effect` keyed on the arg, not a constant return. (6) don't stub the method under test (zero internal coverage) or use `inspect.getsource()` as a behavior proxy. (7) `ExplainNearMiss` has no `graph_provenance` — check provenance only on `results[]`.
- **[2026-06-29] adding a kwarg to a widely-stubbed method**: before running the suite, `grep -rn "def _hybrid\|def <method>" tests/` and fix every stub/local `_hybrid`/`_search` shadow (type-annotation variants defeat `replace_all`); enumerate ALL fanout call sites (RAG-fusion path often has 2× the happy path, incl. try/except fallbacks). Update stale `assert_awaited_once_with(...)`/`assert_called_once_with(...)` to include the new kwarg. A defensive `assert param is None` is dead code unless every caller forwards the param.
- **[2026-07-03] shared helpers / dead code**: extract a shared `_validate_*`/`_table_name`/`_file_exceeds_limit` helper whenever two+ sites need the same rule (they drift immediately); MCP validation needed in >1 tool goes to a module-level `_validate_*` returning `McpErrorResponse | None`. Hoist MCP validation tuples (`_VALID_GRAPH_MODES`) to module level (testable/greppable). After implementing, grep that plan-named helpers are actually called (implementers re-inline them). Use key presence/absence (`del dict[key]`) over a `completed` flag; collapse >2 correlated per-item dicts into one dataclass (avoids TOCTOU).
