## Plan-Making & Agent Process
- **[2026-08-10] (×52) verify before acting**: untracked backlog files ≠ open bugs — use `git ls-files Documentation/Completed/ | grep <ID>` (not bare `ls`) to check committed Completed reports; if found AND tests pass, just trash the stale backlog file and move on. pre-reproduce: `ls Documentation/Completed/ | grep <ID>` + `git log --oneline | grep <ID>` FIRST — both hit = bug *probably* closed, but that pair is NOT proof: run `git log --oneline -- <file the fix touched>` for LATER commits and read the CURRENT source, because a follow-up "fix pre-existing test failures" commit can revert a shipped fix and invert its regression test to assert the buggy behavior, leaving the suite green (248bae1b did exactly this to S561's wizard default-key omission). A green test proves only that code and test agree — diff the test against the DOC contract too. `git log --oneline -- <handler> <test>` + run existing test BEFORE any fix.
